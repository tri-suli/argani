# Icon font

`material-symbols-outlined-subset.woff2` is a subset of Material Symbols Outlined (static: weight 400, fill 0, grade 0, optical size 24) holding only the icons listed in `src/constants/icons.ts`. It was produced by Google Fonts' own subsetting (`fonts.googleapis.com/css2?family=Material+Symbols+Outlined&icon_names=...`); see `office/README.md` to regenerate it.
